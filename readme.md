# Chinese Taipei Touch Association Almanac

An almanac website for the Chinese Taipei Touch Association.

- Front-end: Eleventy site (project root)
- CMS: Sanity Studio in `studio/`

## Sanity Studio migration status

This repository still contains Sanity Studio v2-style configuration in `studio/` (for example `sanity.json` and `part:@sanity/*` schema imports).

Sanity’s official guidance is to migrate **v2 → v3 first**, then upgrade one major version at a time for later releases.

For the project-specific migration checklist and examples, see:

- [`studio/README.md`](studio/README.md)
